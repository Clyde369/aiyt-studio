2 · Pick the niche

The AI shortlists niches, checks each against this month's real Shorts, and scores the chance a new channel grows and earns.

3 · Create the channel on YouTube, then link it

  1. Create the channel: YouTube → Switch account → Create a channel. Use the name and handle above (tap to copy).
  2. Google secrets: already set in Settings? If not, add your OAuth client ID and secret there (one time, works for every channel).
  3. Press Link my new channel and pick it on Google's screen. The app then applies the banner, description, keywords and playlists, and starts finding the best shorts for the niche.

How to get these (5 minutes, one time)
  1. Open Google Cloud Console and create a project.
  2. Enable the YouTube Data API v3.
  3. Set up the OAuth consent screen (External) and add your Google account as a test user.
  4. Create an OAuth client of type Desktop app and paste its ID and secret here.
  5. Uploads from a new, unaudited Google project are locked to private by YouTube. To post public videos, request the free API audit.
